# Miniguia de Educação Financeira com NotebookLM

## Descrição

Projeto prático de aprendizagem ativa utilizando IA generativa e NotebookLM para criação de um caderno temático sobre educação financeira.

## Objetivos

- Compreender conceitos básicos de finanças pessoais
- Estudar orçamento pessoal e familiar
- Entender juros compostos
- Aplicar IA como ferramenta de aprendizagem

## Estrutura do Repositório

📁 fontes → PDFs utilizados no NotebookLM  
📁 resumo → Miniguia consolidado  
📁 imagens → Prints e mapas mentais  
📁 pdf → Versão final em PDF

## Tecnologias Utilizadas

- NotebookLM
- GitHub
- Markdown
- IA Generativa
- MagicPath AI
